# 未体験ゾーン（mitaiken）

**Product Constitution v0.2**

> まだ知らない「やってみたい」を見つける。
> やってみたことを残す。
> その積み重ねが、自分の人生になる。

未体験ゾーンは、日常の中に小さな「初めて」を増やし、
これからの楽しみと、これまでの体験を残していくためのプロダクトです。

「何か面白いことないかな」
「これ、ちょっとやってみたいな」

そんな気持ちから始まり、
いつか振り返ったときに
「いろいろやったな。楽しかったな」
と思える記録が残ることを目指します。

そして、このプロダクトを作ること自体もひとつの「未体験」として楽しみます。

## Core Experience

```
探す
  ↓
やってみたい
  ↓
未来の楽しみとして貯める
  ↓
実際にやる
  ↓
🎉 やってみた！
  ↓
人生の記録として残る
```

## Product Principles

### 1. 小さく作る。すぐ触る。面白ければ育てる。

最初から完璧な仕様を作らない。  
実際に触り、違和感を見つけ、直しながら育てる。

### 2. 楽しさを最優先する。

収益化や利用頻度を上げるために、  
プロダクトをつまらなくしない。

まず作る人自身が「使いたい」と思えるものにする。

### 3. ユーザーを急かさない。

「今日やりましょう」  
「毎日続けましょう」  
という義務感を作らない。

未体験は今日やらなくてもいい。  
未来の楽しみとして取っておいていい。

### 4. 競わせない。

ランキング、連続記録、ノルマなど、  
他人や過去の自分との競争を前提にしない。

自分のペースで楽しめればいい。

### 5. ユーザーの時間を奪わない。

長時間使わせることや、  
毎日アプリを開かせることを成功とは考えない。

暇なとき、何かしたくなったときに思い出してもらえればいい。

「暇だから開く → 少し楽しくなる → 閉じる」  
くらいがちょうどいい。

### 6. 利用頻度より、長く付き合えることを大切にする。

毎日使われなくてもいい。  
年に数回でも、何年も残しておきたいアプリを目指す。

半年ぶりに開いても、また楽しい。  
何年後でも自分の記録に戻ってこられる。

そんなプロダクトにする。

### 7. 「やってみた」は人生の記録として扱う。

「やってみた」は単なる完了フラグではない。

いつ、どこで、何をして、  
どんなことを感じたのか。

使い続けるほど、  
その人自身の体験の履歴になることを大切にする。

### 8. 正確さを強制しない。

昔の体験について、  
正確な日付を覚えていなくてもいい。

日付、年月、年だけ、  
「もっと以前」「覚えていない」でも記録できる。

記録することを面倒な作業にしない。

### 9. ユーザーの人生の記録を人質にしない。

記録されたデータはユーザー自身のもの。

いつでも持ち出せること、  
サービスがなくなっても残せることを大切にする。

過去の思い出を見るために課金を要求するような設計にはしない。

### 10. SNSにすることを目的にしない。

誰かに見せるためではなく、  
まず自分自身のために記録する。

「映える」必要はない。  
いいねやフォロワー数で体験の価値を決めない。

### 11. 技術より体験を優先する。

新しい技術を使うこと自体を目的にしない。

ただし、  
セキュリティ、データ保護、バックアップなど、  
ユーザーの大切な記録を守るための技術には妥協しない。

### 12. AIと一緒に作る。

意思決定は人間。  
実装・検証・整理はAIを積極的に活用する。

小さなチームでも、  
思いついたものをすぐ形にできる開発を楽しむ。

## Development Style

**作る → 触る → 面白いか確認する → 直す → また作る**

迷ったときは、

- 未体験を楽しむことにつながる？
- 面倒を増やしていない？
- 今、本当に必要？
- もっと小さく試せない？
- 作っている自分も面白い？

で判断します。

## What We Don't Want

未体験ゾーンは、以下のようなプロダクトを目指しません。

- タスク管理アプリ
- 習慣化アプリ
- 毎日の利用を要求するアプリ
- ランキングで競うアプリ
- SNS映えを競うアプリ
- 過剰な通知を送るアプリ
- ユーザーの記録を囲い込むアプリ

## Long-term Vision

未体験ゾーンを使い続けることで、

「これからやってみたいこと」と  
「これまでやってみたこと」が少しずつ積み重なっていく。

10年、20年経ったとき、  
それは単なるアプリの履歴ではなく、  
その人自身の人生の記録になっている。

本人が振り返って、

「いろいろやったな。楽しかったな」

と思えること。

そしていつか大切な人がその記録を見たとき、

「この人、ちゃんと人生を楽しんでいたんだな」

と感じられること。

それが未体験ゾーンの目指す未来です。

## Definition of Success

成功はDAUや利用時間だけでは測りません。

1. 作った本人が実際に使いたいと思える
2. 知らない誰かが「やってみたい」を見つける
3. 実際に新しい体験につながる
4. 体験の記録が少しずつ積み重なる
5. 数年後にもアプリが残っている
6. ユーザーが「この記録は消したくない」と思える
7. いつか振り返って「楽しかった」と思える
