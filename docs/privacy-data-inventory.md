# わたしのはじめて帖 個人データ棚卸し

最終更新: 2026-08-30

## 目的

「わたしのはじめて帖」で取り扱うユーザーデータと外部サービスを把握し、プライバシーポリシー、利用規約、アプリ内表示と実装の食い違いを防ぐための内部管理資料。

原則として、実際に取得・利用している情報だけをプライバシーポリシーに記載する。将来候補は本資料で別管理し、導入時にプライバシーポリシーおよびアプリ内表示の改定要否を確認する。

## 実装確認済み事項

-   認証は Supabase Auth のメールOTP方式を利用する。
-   初回OTP送信時はアカウント作成を許可する現在の実装になっている。
-   ユーザー作成時に `profiles`
    が作成され、ユーザー所有データはユーザーに紐づけて管理する。
-   ユーザー所有テーブルは cascade delete
    を基本とし、アカウント削除時はユーザーデータ全削除を原則とする。
-   写真は元ファイルをそのまま保存せず、ブラウザ上で最大1200pxのJPEGとして再生成する。元画像のEXIFは原則引き継がない。
-   RLSにより、ユーザー所有データは本人のアカウントから扱うことを基本とする。
-   未ログイン時は個人データを表示せず、保存操作時に登録またはログインを求める。
-   ログアウト時は端末内に一時保存した体験記録、写真、メモ、設定情報等の個人データを削除する。

## アカウント削除・バックアップ方針

-   アカウント削除時は、アカウントに紐づく登録情報、体験記録、写真、メモ、設定情報その他のユーザーデータを削除する。
-   バックアップには削除済みデータが一定期間残存する可能性がある。
-   バックアップ上の情報は所定の保存期間の経過に伴い削除する。
-   障害復旧でバックアップから全体を復元した場合も、退会済みユーザーのデータを恒久的に復活させない運用・復旧手順を設ける。

## 生成AIに関する方針

-   ユーザーが登録した写真、メモ、体験記録その他の個人データを、生成AIモデルの学習目的に利用しない。
-   外部生成AIへユーザーデータを送信する機能は現時点で設けない。
-   将来AI機能を導入する場合は、実装前に本資料、プライバシーポリシー、アプリ内表示、同意要否を見直す。

## プライバシー上シンプルに保つ機能方針

現時点では以下の機能を設けない。

-   公開プロフィール
-   SNSへの自動公開
-   ユーザー同士の共有機能
-   フォロー・フォロワー
-   ユーザー間DM
-   他ユーザーへのコメント

ユーザーが登録した「私の記録」は、原則として本人のみが閲覧する設計とする。

## 将来候補（未実装）

以下は導入するまで「現在取得している情報」としてプライバシーポリシーに記載しない。

-   アクセス解析（Google Analytics等）
-   案内・おすすめメール
-   エラー監視サービス
-   アフィリエイト等の外部リンクに伴う計測

## 外部サービス追加時の開発ルール

新しい外部サービスやSDK等を本番導入するときは、実装前に以下を確認する。

1.  どのユーザーデータが取得されるか
2.  どのデータが外部事業者へ送信されるか
3.  何の目的で利用するか
4.  どのくらい保存されるか
5.  本資料を更新する
6.  プライバシーポリシーの改定が必要か確認する
7.  アプリ・Web上の表示や同意の変更が必要か確認する
8.  必要な対応を完了してから本番導入する

## プライバシーポリシーとの関係

本資料は内部管理用であり、そのままユーザー向けに公開するものではない。

プライバシーポリシーでは、実際のサービス仕様に基づいて、取得する情報、利用目的、外部サービスへの送信、第三者提供、安全管理、削除・問い合わせ等を、ユーザーが理解できる表現で記載する。
