# わたしのはじめて帖 個人データ棚卸し

最終更新: 2026-08-27

## 目的

「わたしのはじめて帖」で取り扱うユーザーデータと外部サービスを把握し、プライバシーポリシー、利用規約、アプリ内表示と実装の食い違いを防ぐための内部管理資料。

原則として、実際に取得・利用している情報だけをプライバシーポリシーに記載する。将来候補は本資料で別管理し、導入時にプライバシーポリシーおよびアプリ内表示の改定要否を確認する。

## 外部サービス

### Supabase

想定用途:
- ユーザー認証
- PostgreSQLデータベース
- 写真等のファイル保存
- 認証・システムログ

確認事項:
- 実際に利用する機能
- 保存リージョン
- 自動取得されるログ情報
- ログ・バックアップの保持期間
- アカウント削除時のDB・Storage・バックアップの扱い

## プライバシー上シンプルに保つ機能方針

現時点では以下の機能を設けない。

- 公開プロフィール
- SNSへの自動公開
- ユーザー同士の共有機能
- フォロー・フォロワー
- ユーザー間DM
- 他ユーザーへのコメント

ユーザーが登録した「私の記録」は、原則として本人のみが閲覧する設計とする。

## 要確認事項

- 写真アップロード時のEXIF（撮影日時・位置情報等）を保持するか削除するか
- 運営者が障害対応等でユーザーデータを閲覧できる範囲と運用ルール
- アカウント削除時に削除するデータの範囲
- バックアップからの削除タイミング
- ログの保存項目と保存期間
- 認証メールを送る外部サービス
- 問い合わせ窓口と保存方法

## 将来候補（未実装）

以下は導入するまで「現在取得している情報」としてプライバシーポリシーに記載しない。

### アクセス解析

例: Google Analytics等。

導入時に確認すること:
- 取得情報
- Cookie・端末識別子等の利用
- 利用目的
- 外部送信先
- オプトアウト手段
- プライバシーポリシーへの追記
- アプリ・Web側で必要な表示や同意

### 案内・おすすめメール

導入時に確認すること:
- 配信サービス
- メールアドレス等の外部送信
- 配信履歴・エラーログ
- 配信停止方法
- 登録時の同意・表示方法

### エラー監視サービス

導入時に確認すること:
- エラーログに含まれるユーザー情報
- 外部送信される情報
- 保存期間
- プライバシーポリシーへの追記要否

### アフィリエイト等の外部リンク

導入時に確認すること:
- Cookie等の利用有無
- 外部サイトへ遷移することの表示
- プライバシーポリシー・サイト表示への影響

## 外部サービス追加時の開発ルール

新しい外部サービスやSDK等を本番導入するときは、実装前に以下を確認する。

1. どのユーザーデータが取得されるか
2. どのデータが外部事業者へ送信されるか
3. 何の目的で利用するか
4. どのくらい保存されるか
5. 本資料を更新する
6. プライバシーポリシーの改定が必要か確認する
7. アプリ・Web上の表示や同意の変更が必要か確認する
8. 必要な対応を完了してから本番導入する

## プライバシーポリシーとの関係

本資料は内部管理用であり、そのままユーザー向けに公開するものではない。

プライバシーポリシーでは、実際のサービス仕様に基づいて、取得する情報、利用目的、外部サービスへの送信、第三者提供、安全管理、削除・問い合わせ等を、ユーザーが理解できる表現で記載する。
